# 方案与技术取舍

采用Python原生循环，使用Pydantic校验输入/动作/脚本、httpx请求兼容Chat Completions接口、dotenv读取本地配置。无Agent框架；版本从requirements及实际环境记录核对。

AgentRunner每轮将输入、稿件、已检索素材、完整工具反馈、历史动作、剩余步数交给LiveAdapter。模型返回动作名、参数与简要公开依据；运行时校验后执行并记录观察，下一轮再交给模型。Runtime的条件分支负责动作分派和成功门禁；不会自动选择重试、改查询或删镜头。MockAdapter是标注清楚的固定动作列表，不作为真实决策证据。

| 文件 | 职责 |
|---|---|
| src/agent.py | 有界循环、动作执行与结果组装 |
| src/llm_adapter.py | 真实模型/Mock隔离、JSON协议、HTTP与错误 |
| src/schemas.py | 严格参数及稿件/素材约束 |
| src/tools.py | 三工具、数据加载、工具异常安全 |
| src/state.py | 状态、检查失效、内容指纹与完成条件 |
| src/tracing.py | 逐步JSONL和最终JSON、密钥脱敏 |
| scripts/ | 当前版本及运行证据的离线审计 |
| eval/ | 同一实现使用的评估函数和合成测试数据；不含候选实现副本 |

检索是关键词包含匹配，返回事实原文及ID。估时逐镜取旁白时间、字幕阅读时间与最短镜头时间的最大值，再加转场；总和与目标上限比较。品牌工具核验禁词、来源/事实ID、声明与原文、风险及所有可见字段。选择保守原文覆盖来阻止无据效果，代价是可能拒绝合理自由改写。

script_version覆盖脚本、用户输入、素材及规则。任何改稿和业务工具错误使当前检查失效。只有当前版本时长及品牌规则两项通过、输入和证据齐全时finish才可completed，导出时再次核验。默认max_steps=12，达到上限为incomplete，异常尝试也占一步。

Trace记录步骤、参数、完整返回、公开依据、实际下一动作、请求/响应及前后指纹，不记录服务商私有推理。工具异常与模型异常均如实记录。源码、文档、配置和保留证据由唯一VERSION.json冻结；该本地内容版本不是远程Git提交SHA。
